# 肠梗阻急症处理指引卡

## 🚨 紧急情况识别
**立即拨打120的情况：**
- 剧烈腹痛伴呕吐
- 腹胀明显，停止排气排便
- 呕吐物为粪便样
- 腹部触及包块
- 发热、脱水症状
- 腹膜刺激征（腹肌紧张、反跳痛）

---

## 1. 紧急处理步骤

### 🔴 立即行动（前5分钟）
1. **保持冷静**，让患者采取舒适体位（侧卧或半坐位）
2. **禁食禁水**，避免加重肠道负担
3. **记录症状**：
   - 腹痛开始时间、性质、部位
   - 呕吐次数、颜色、性状
   - 最后排便排气时间
4. **测量生命体征**：血压、脉搏、体温
5. **准备就医物品**：身份证、医保卡、病历、影像资料

### 🟡 持续监护（5-30分钟）
- 每5分钟观察腹痛变化
- 记录呕吐物性状和量
- 观察腹胀程度
- 监测排气排便情况
- 注意脱水征象

## 4. 处理风险体系

### ⚠️ 高危风险信号
**立即呼叫120：**
- 剧烈持续性腹痛
- 腹膜刺激征阳性
- 呕吐物为粪便样
- 发热>38.5°C
- 脱水严重（皮肤弹性差、尿少）
- 腹部触及包块

### 🟨 中等风险管理
**密切观察，准备就医：**
- 间断性腹痛
- 轻度腹胀
- 偶有呕吐
- 排气减少但未完全停止

### 🟢 低风险监护
**居家观察，定期复查：**
- 轻微腹部不适
- 排便习惯改变
- 食欲下降
- 无明显腹胀

### 📊 风险评估表
| 症状 | 低风险 | 中风险 | 高风险 |
|------|--------|--------|--------|
| 腹痛 | 轻微 | 中等 | 剧烈持续 |
| 呕吐 | 无/轻微 | 偶有 | 频繁/粪样 |
| 腹胀 | 轻微 | 中等 | 明显 |
| 排气排便 | 减少 | 明显减少 | 完全停止 |
| 体温 | 正常 | 轻度升高 | >38.5°C |
| 处理 | 观察 | 准备就医 | 立即120 |
