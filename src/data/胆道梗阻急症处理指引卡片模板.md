# 胆道梗阻（黄疸）急症处理指引卡

## 🚨 紧急情况识别
**立即拨打120的情况：**
- 急性黄疸伴高热（>38.5°C）
- 剧烈右上腹痛伴寒战
- 意识障碍或精神症状
- 血压下降、休克征象
- 皮肤巩膜深度黄染
- Charcot三联征（发热、黄疸、右上腹痛）
- Reynolds五联征（三联征+休克+意识障碍）

---

## 1. 紧急处理步骤

### 🔴 立即行动（前5分钟）
1. **保持冷静**，让患者采取舒适体位（半坐位或右侧卧位）
2. **测量体温**，观察寒战情况
3. **记录症状**：
   - 黄疸出现时间和程度
   - 腹痛性质、部位、放射痛
   - 发热程度和伴随症状
   - 大小便颜色变化
4. **测量生命体征**：血压、脉搏、体温、呼吸
5. **准备就医物品**：身份证、医保卡、病历、既往检查资料

### 🟡 持续监护（5-30分钟）
- 每5分钟监测体温变化
- 观察黄疸加深程度
- 记录腹痛变化
- 监测意识状态
- 观察尿液颜色（茶色尿）
- 注意皮肤瘙痒程度

## 4. 处理风险体系

### ⚠️ 高危风险信号
**立即呼叫120：**
- 体温>38.5°C伴寒战
- Charcot三联征完整
- 血压下降<90/60mmHg
- 意识障碍或精神症状
- 急性腹膜炎征象
- 深度黄疸（胆红素>200μmol/L）

### 🟨 中等风险管理
**密切观察，准备就医：**
- 轻中度黄疸
- 间断性右上腹痛
- 低热（37.5-38°C）
- 食欲不振、乏力

### 🟢 低风险监护
**居家观察，定期复查：**
- 轻度黄疸
- 无发热
- 轻微腹部不适
- 大便颜色轻度变浅

## 📚 疾病知识要点

**胰腺肿瘤病人胆道梗阻常见原因：**
- 胆管肿瘤
- 胰头癌
- 胆管狭窄


✅ Charcot三联征（夏科氏三联征）
-发热寒战（寒战高热）
-黄疸（皮肤/巩膜黄染）
-右上腹痛（剑突下或右上腹阵发性绞痛）

病理基础：胆道梗阻（如结石）继发细菌感染，导致胆汁淤积和炎症反应

✅ Reynolds五联征（雷诺五联征）

-Charcot三联征（上述三项）
-休克（血压下降、脉搏细速等感染性休克表现）
-意识障碍（中枢神经抑制：嗜睡、谵妄或昏迷）

关键机制：化脓性胆管炎进展至脓毒血症，细菌毒素突破血脑屏障5

⚠️ 重要补充说明
诊断意义：
Charcot三联征 → 急性胆管炎（早期）
Reynolds五联征 → 急性梗阻性化脓性胆管炎（AOSC）（危重症）
治疗紧迫性：
Reynolds五联征死亡率高达20-50%，需 12小时内紧急胆道减压（如ERCP引流）


**选择急诊手术**
[了解ERCP和PTCD的区别和治疗效果](https://mp.weixin.qq.com/s/g3Vn8sVJhfZpjc816v6qZQ)
重点提醒和判断，急诊手术医生选择方案，利于患者后续治疗。充分了解支架可能带来的感染风险，以及ptcd的适应症。如果急诊无法处置，迅速考虑上级专业医院，不能耽误。


- 早期识别和治疗预后良好
- 合并感染需积极抗感染治疗
- 及时胆道引流是关键
